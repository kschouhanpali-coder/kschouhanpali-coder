I sit at the layer between **what a model can do** and **what a system needs it to do reliably** — that gap is where most AI products actually fail, and it's where I work.

Not "write me a better ChatGPT prompt." Think: multi-turn agents that don't drift, retrieval pipelines that don't hallucinate their sources, and evaluation harnesses that catch regressions before your users do.

```diff
- Prompting is not a hack you bolt on at the end.
+ Prompting is the interface layer of the entire system — treat it like one.
```
